How it works

The text is lower-cased and stripped of links, digits and punctuation. Source giveaways such as a "(Reuters)" dateline are removed, so the model can't just recognise the outlet. What's left becomes TF-IDF weights over 30,000 words and word pairs, which a logistic regression turns into a probability.

The same arithmetic runs in Python for training and in JavaScript here. A test feeds both the same set of texts and requires the answers to agree to within 0.001. The whole model is a 0.9 MB file.

The first list measures articles the model never trained on, but written by the same outlets or datasets it did train on. The second leaves one whole source out. There the model is close to a coin flip, and sometimes worse, because each dataset has its own idea of what "fake" looks like. Expect useful answers only for news that resembles the first list.

What it can't do

  • It scores writing style learned from mostly English, US-politics articles from 2016 and 2017. It does not check whether any claim is true.
  • Satire, opinion columns, other languages and brand-new topics can fool it. It cannot tell when a text is outside what it knows, so it sounds just as sure when it is wrong. Under 10 words it says unsure.
  • Use it as a prompt to look closer, then check the source and a fact-checking site.
